# Auditoria npm — 9 de novembro de 2026

`npm audit --json` encontrou 8 vulnerabilidades moderadas, nenhuma alta ou crítica. Todas pertencem à cadeia de desenvolvimento do ESLint e não entram no bundle de produção.

| Pacote | Relação | Ambiente | Causa |
|---|---|---|---|
| `eslint-config-next` | direta | desenvolvimento | depende de `typescript-eslint` |
| `typescript-eslint` | transitiva | desenvolvimento | agrega `@typescript-eslint/*` |
| `@typescript-eslint/eslint-plugin` | transitiva | desenvolvimento | cadeia do parser |
| `@typescript-eslint/parser` | transitiva | desenvolvimento | cadeia do `typescript-estree` |
| `@typescript-eslint/type-utils` | transitiva | desenvolvimento | cadeia do `typescript-estree` |
| `@typescript-eslint/typescript-estree` | transitiva | desenvolvimento | usa `minimatch` vulnerável |
| `@typescript-eslint/utils` | transitiva | desenvolvimento | cadeia do parser |
| `minimatch` | transitiva | desenvolvimento | GHSA-g3hv-75wg-m249, DoS por glob complexo |

O npm oferece correção propondo `eslint-config-next@15.5.29`, downgrade major incompatível com Next.js 16.4.5. O risco é baixo porque a entrada de glob é controlada pelos scripts locais. Nenhuma atualização ou `npm audit fix --force` foi aplicada; aguardamos uma versão compatível.
